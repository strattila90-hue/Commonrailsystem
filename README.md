# Common Rail Gyakorló

Common rail dízel üzemanyagrendszer oktató app: felépítés, működő szimulátor és sorrend gyakorló.
Telepíthető webapp (PWA), offline is működik.

## Közzététel
- **GitHub Pages:** Settings → Pages → Deploy from a branch → main / (root)
- **Vercel:** Add New → Project → a GitHub repó importálása → Framework: Other → Deploy (build nem kell)

## Frissítés
Új verzió feltöltésekor az `sw.js` fájlban a `CACHE` nevét léptesd (v2 → v3), különben a telefonok a régit mutatják.
